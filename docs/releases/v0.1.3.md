## Overlay & metrics

- Set how far the overlay sits from the selected corner. Save changes during a game to move it without restarting.
- See the default values on the Edge spacing, Scale, and Opacity sliders.
- Choose FPS only under Layout. Saved Grid layouts open in Telemetry and keep their other settings. Ribbon and Telemetry look the same as before.

## Compatibility

Before going back to v0.1.2, set Edge spacing to 12 px and save. v0.1.2 cannot read game profiles saved with custom spacing.
