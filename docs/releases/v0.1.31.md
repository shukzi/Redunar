- Added NVIDIA graphics support for in-game metrics and hardware Instant Replay through Vulkan Video, including Vulkan and supported desktop OpenGL games.
- Removed the Stable/Beta selector. Hardware features now use their capability checks automatically while preserving existing saved preferences.
- Improved NVIDIA recording startup, GPU memory allocation and recovery from capture failures, and reduced frame-import and power-monitoring overhead.
- Reduced redundant text and control updates during polling and moved hardware discovery off the window thread, preserving the interface and native scrolling.

Existing profiles, history and recordings are preserved. This release adds no persisted-format migration. The Replay preferences format introduced in v0.1.28 still requires a compatible reader; back up preferences before downgrading to an older release. Restart Redunar after updating and relaunch any game already using Redunar so it loads the matching capture components.
