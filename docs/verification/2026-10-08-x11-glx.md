## Result and scope

A privately loaded GLX provider reproduces a concrete sidecar defect without
hardware: the original calls run without preload, but Redunar's hooks cannot
reach that provider through RTLD_NEXT, so swap and destruction never run.
A handle-specific lookup can also be redirected to a different global provider.
The new `glx_lookup` module preserves the exact original target unless the hook's
forwarding target matches. Matching global providers keep the capture hooks.
Unreachable/mismatched GLX targets bypass optional capture.

Only the GLX swap/destruction dlsym branches change. EGL, Vulkan, Steam startup,
profiles, persistence and desktop configuration are unchanged. The guard applies
to GLX clients under X11 or Xwayland; it does not select a display backend.

This is **not confirmed as the CachyOS/KDE X11 ARC Raiders root cause**.
The owner reports the game opens without Redunar's option, Wayland works, and
believes both open/closed Redunar were tried. The bootstrap audit had already
passed private virtual-X11 startup/fallback fixtures; this new check exercises
ELF forwarding instead. No actual game/driver/KDE acceptance was performed.
