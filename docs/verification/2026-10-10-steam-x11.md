# Steam X11 launch integration — October 10, 2026

## Change and review

The integration includes contributor PR #2 revision `d8c3e91` over base
`bfb58f8`, including the refreshed pinned Bookworm Rust image. That contributor
revision addresses the original native-runtime, non-UTF-8 Proton and inherited
preload findings. Additional private-wrapper fixtures reproduced two remaining
failures: a foreign space-separated preload was removed, and unavailable or
malformed activation lost inherited preloads. Detection also needs to distinguish
a Proton executable from a native executable inside a directory named `proton`.

The packaged wrapper now checks the literal executable basename without UTF-8
conversion, removes only Redunar OpenGL entries from activated Proton launches,
preserves foreign preload bytes with both loader separators, and applies an
explicit empty override when nothing remains. Native runtime launches retain
OpenGL capture; unavailable activation preserves inherited environment and argv.
Vulkan capture, session/profile ownership, persisted formats, capability gates,
background supervision and cleanup retain their existing contracts.

The owning behavior is documented in ARCHITECTURE and REPLAY; the private broker
fixtures use absent library paths and fake commands, with no game or GPU opened.
